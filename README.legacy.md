# PulseMDT 1.x FiveM connector

This repository's root resource and `pulsemdt-connector.zip` releases are for PulseMDT 1.x. The current PulseMDT 2 dashboard requires the [2.0 game pack](https://github.com/PulseSystemsDev/pulsemdt-connector/releases/latest/download/pulse-game-pack.zip) and a game server key.

For an existing 1.x deployment, keep its API key and guild ID configuration until you migrate. Do not use those values with PulseMDT 2.
